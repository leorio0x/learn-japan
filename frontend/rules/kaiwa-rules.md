## Halaman kaiwa

- display kaiwa dengan opsi [lesson, semua lesson]
- tampilkan pola, pertanyaan, dan jawaban (kanji + hiragana/katakana)
- opsi hide terjemahan

## Halaman tebak kaiwa

- pertanyaan dengan opsi [pertanyaan,jawaban,acak] dari kaiwa
- jawaban user berupa "pertanyaan dari kaiwa" jika
  pertanyaan soal berupa "jawaban dari kaiwa" begitupun sebaliknya
- pertanyaan dan jawaban berpasangan berdasarkan urutan index
- terdapat opsi hide kanji

## Halaman CRUD kaiwa

- input berupa :

1. pola [pola_pertanyaan, pola_jawaban, deskripsi, contoh] (bisa lebih dari satu)
2. contoh pertanyaan [bentuk full kanji, hiragana/katakana [opsional], terjemahan] (bisa lebih dari satu)
3. contoh jawaban [bentuk full kanji, hiragana/katakana[opsional], terjemahan] (bisa lebih dari satu)
4. lesson
5. buku dengan input type select [minna no nihonggo 1, minna no nihonggo 2]
6. opsi untuk bulk delete
